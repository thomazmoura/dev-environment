# Agents pane keys

## Move

| Key | Does |
|---|---|
| `j` / `k` | Down / up (arrows too) |
| `g` / `G` | First / last row |
| `Enter` | Jump to the agent's pane |

## Pane

| Key | Does |
|---|---|
| `r` | Reload the feed |
| `R` | Reload and restart the sampler |
| `?` | This list |
| `Ctrl-C` | Close the pane |
